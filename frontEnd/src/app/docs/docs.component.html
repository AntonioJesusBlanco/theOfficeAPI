Documentación de la API: The Office

Esta API proporciona información sobre los personajes de la serie The Office tanto de la version americana como de la inglesa. A continuación, se describen las distintas peticiones que puedes realizar al servidor, los campos que contiene la respuesta y ejemplos prácticos sobre los mismos.

Obtener todos los personajes

Método: GET

URL: /api/personajes

Descripción: Devuelve una lista con todos los personajes.

Respuesta: Un array de objetos, donde cada uno representa un personaje:

Campos:

  • nombre_actor (String) Nombre del actor
  • apellido_actor (String) Apellido del actor
  • nombre_personaje (String) Nombre del personaje
  • primera_aparicion (String) Primera aparición del personaje
  • version (String) Versión de la serie (US/UK)
  • frases (Array) (opcional) Lista de frases más famosas (cada una con texto y capítulos)
  • foto (String) (opcional) URL de la imagen del personaje

Obtener un personaje por nombre

Método: GET

URL: /api/personajes/:name

Parámetros: name (String) Nombre del personaje (en minúsculas y sin espacios)

Descripción: Devuelve un objeto con los datos del personaje solicitado.

{
  "nombre_personaje": "Michael Scott",
  "nombre_actor": "Steve",
  "apellido_actor": "Carell",
  "foto": "/images/michael_scott_hd.webp",
  "primera_aparicion": "Temporada 1, Episodio 1",
  "version": "US",
  "frases": [
    {
      "texto": "That's what she said.",
      "capitulos": ["Temporada 2, Episodio 2", "Temporada 3, Episodio 5..."]
    },
    {
      "texto": "I am Beyoncé, always.",
      "capitulos": ["Temporada 5, Episodio 23"]
    }
  ]
}

Añadir un nuevo personaje

Método: POST

URL: /api/personajes

Descripción: Añade un nuevo personaje a la base de datos.

Cuerpo JSON esperado

{
  "nombre_personaje": "Dwight Schrute",
  "nombre_actor": "Rainn",
  "apellido_actor": "Wilson",
  "foto": "/images/dwight_schrute_hd.webp",
  "primera_aparicion": "Temporada 1, Episodio 1",
  "version": "US",
  "frases": [
    {
      "texto": "Whenever I'm about to do something, I think, 'Would an idiot do that?' And if they would, I do not do that thing.",
      "capitulos": ["Temporada 1, Episodio 3"]
    },
    {
      "texto": "Bears. Beets. Battlestar Galactica.",
      "capitulos": ["Temporada 3, Episodio 3"]
    }
  ]
}

Respuesta exitosa

{
"message": "Personaje añadido con exito (simulado)"
}

En caso de error: La respuesta seran

{
"message": "Falta campos requeridos: nombre_personaje, nombre_actor"
}

{
"message": "Personaje ya existente"
}

Actualizar un personaje existente

Método: PUT

URL: /api/personajes/:name

Descripción: Actualiza la información de un personaje específico (por su nombre).

Cuerpo JSON esperado Igual que en POST.

{
  "nombre_personaje": "Dwight Schrute",
  "nombre_actor": "Rainn",
  "apellido_actor": "Wilson",
  "foto": "/images/dwight_schrute_hd.webp",
  "primera_aparicion": "Temporada 1, Episodio 1",
  "version": "US",
  "frases": [
    {
      "texto": "Whenever I'm about to do something, I think, 'Would an idiot do that?' And if they would, I do not do that thing.",
      "capitulos": ["Temporada 1, Episodio 3"]
    },
    {
      "texto": "Bears. Beets. Battlestar Galactica.",
      "capitulos": ["Temporada 3, Episodio 3"]
    }
  ]
}

Respuesta exitosa

{
"message": "Personaje Michael Scott actualizado correctamente (simulado)"
}

En caso de error: La respuesta sera:

{
"message": "Falta campos requeridos: nombre_personaje, nombre_actor"
}
